## Implemented: Kelp Passage point-cloud asset / import fixture

Added scripts/generate_kelp_cloud.cjs (Node 18+ offline tool, no npm packages). It builds an original, fixed-budget 3D composition with 28 staggered kelp stalks, sampled tapered ribbon blades, sparse substrate and marine-snow positions. The center stays open. Ghost (default, bone-white) and Lagoon (cyan/jade) bake different RGB values into identical geometry. The generator emits ASCII XYZRGB PLY, not a scan, splat, mesh, animated kelp simulation, or actual caustic shader. The seed/palette and synthetic origin are embedded in the header. Existing viewer import normalizes the extent and may recolor via its current display palette; no importer, shader, scene selector, registry, server or default changes. The file is generated locally and exclusive-create refuses an existing output path.

Reproduce on Windows/Linux/macOS with Node and existing Studio:

```sh
node scripts/generate_kelp_cloud.cjs kelp-ghost.ply
node scripts/generate_kelp_cloud.cjs kelp-lagoon.ply --palette lagoon
node tests/test_kelp_cloud.cjs
projection-studio
```

Open the new PLY via Spatial Memories file picker or drag/drop. No Node requirement for viewing a generated PLY; a WebGL2-capable browser and the existing Python local server are sufficient. No camera or microphone permission needed for this asset. Keep outputs outside version control.
