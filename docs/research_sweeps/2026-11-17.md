## Implementation: dependency-free Spore Grove preview

Added `src/projection_mapping/studio_static/spore_grove.js` and wired a **Spore Grove (experimental)** item into Spatial Studio's existing *World* dropdown. It builds a seeded set of approximately **67,495** 7-float points, with mushroom stalks, cap domes, underside gills, sparse ground and about **8,840** highlighted drifting spores. It uses the existing single WebGL2 buffer and shader pipeline; the vertex stage moves marked spores upward and sideways. Geometry is built on scene selection, **not every frame**. Colors stay under the existing Ghost White / Cyan-Magenta / Amber palette and light controls. No images, textures, model weights, JS framework, CUDA path, new server endpoint, package or GitHub workflow were added. No upstream source/assets were copied. The scene stays opt-in, unpromoted and limited to the static preview, and imported scans are not overwritten by changing World.

A small scene-mode switch change regenerates the selected procedural world on selection; switching back to Forest restores the original deterministic baseline. The script must be loaded before studio.js and included with static deployments and PyInstaller's packaged JS glob.

## Validation evidence and limits

- **Executed** deterministic point-budget/finite-value check in the JavaScript execution sandbox: 67,495 points; 8,840 marked spores; exact same Float32 data on repeated generation.
- **Executed** source syntax parsing and a mock-WebGL2 startup + scene-switch regression using the **branch's fetched actual JS** inside an isolated V8 function scope: original forest booted, Spore Grove rendered through the existing buffer contract, forest restored, text point parser still worked. This is a stub GPU test, not shader compilation.
- `tests/test_studio_web.cjs` extended to cover bounded/deterministic spore layout and scene selection; **full Node test run has not been executed** in the project checkout.
- No actual WebGL2 shader compilation, browser photograph, projector, camera, RTX 4050/4080 60-second benchmark, VRAM, F11/ESC window behavior, OR CI test claimed as validated.
- The generator creates ~1.9 MB of Float32 vertex data plus a transient JS point array per scene selection, small compared with the project's 130k preview cap. Actual GC pause and GPU upload time remain to be measured, not inferred.
