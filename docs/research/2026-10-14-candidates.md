# October 14 research follow-up

Window: September 15–October 14, 2026. All items below are research candidates, not tested integrations.

* **Fosfora v2.5.0 (October 12):** MIT OR Apache-2.0 native Rust/WGPU audiovisual compositor. Windows x64 Spout, macOS universal Syphon, Linux x64; Vulkan/Metal GPU for rendering; headless `--signal` publishes versioned OSC audio features without a GPU. M7/M2: evaluate as independent VJ and an optional OSC analysis peer. https://github.com/kevinraymond/fosfora/releases/tag/v2.5.0
* **Open3D v0.20.0 (September 16):** MIT. Gaussian PLY/SPLAT/SPZ plus polygon meshes in one depth-aware scene. M4/M6: offscreen asset/occlusion validation, not a core graphics replacement. Wheels for Windows, Linux, macOS arm64; verify Python/NumPy constraints. https://github.com/isl-org/Open3D/releases/tag/v0.20.0
* **Infinite v0.5.0 (October 10):** MIT source, GPLv3 implications in default VST3-enabled and Linux GPL-codec binaries. Cross-platform node-based audiovisual instrument. M7/M2 external compositor comparison; do not copy code. https://github.com/n1m21n/Infinite/releases/tag/v0.5.0
